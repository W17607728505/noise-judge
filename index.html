第一步·自判类型：工业 / 建筑施工 / 交通运输 / 社会生活（家庭·宠物·装修·商铺·公共活动·设施设备）/ 小区公用设备（电梯·水泵）。

第二步·主管部门：统一热线 12345。
工业·施工·商业固定设备·公用设备 → 生态环境部门；夜间无证施工 → 生态环境+住建/城管；鸣笛/道路 → 公安交管(122)；音响/宠物/家庭/公共 → 公安(110)+社区；小区公用设备 → 物业(首)→生态环境/住建。

第三步·取证五步：日志 → 录音/文字 → 排查锁定 → 证人 → 沟通留痕。

第四步·处罚触发：调解/处理优先，拒不改正方处罚。
《治安管理处罚法》(2025修订·2026-01-01施行) 第88条：社会生活噪声，经基层自治组织/业委会/物业/有关部门劝阻、调解、处理未能制止，继续干扰他人正常生活、工作和学习的，处五日以下拘留或一千元以下罚款；情节严重处五日以上十日以下拘留，可并一千元以下罚款。
第89条：饲养动物干扰他人正常生活，处警告；警告后不改正处一千元以下罚款。
生态环境法典：超标或未尽防控且干扰 → 责令改正；拒改/严重 → 罚款。

噪音源排查七步

  • ① 记录现象：时段、频率、音色、强度。
  • ② 划定空间：上 / 下 / 侧 / 外。
  • ③ 时间维度：固定=人为；夜间增强=结构性传声；随机=偶发/宠物。
  • ④ 排除验证：关设备、离家、邻里同步听。
  • ⑤ 工具定位：分贝仪(参考)、录音、震动手触/杯水、管道听诊。
  • ⑥ 区分传声：空气传声(音响/人声)→声源房间；固体传声(撞击/震动)→经楼板/管道放大。
  • ⑦ 确认来源：时间+位置+声学特征+对方确认，形成证据链。
