# 噪音判官 · Noise Judge

> 一款**完全免费、无广告、零依赖**的噪声维权科普互动游戏。
> 帮普通人搞懂：遇到楼上装修、广场舞、小区水泵、夜间施工这类噪声，**该找谁、要收集什么证据、依据哪一条法律**。

## 这是什么

「噪音判官」把你当成社区里的噪声纠纷调解裁判：用对话收集事实 → 依据规则判定 → 给出公道处置。

- **37 起真实场景案例**，覆盖社会生活、小区公用设备、建筑施工、工业、交通运输五大类
- **判官学院 8 个板块**：学习与考核体系 / 自测题库 / 模拟考 / 官方判决案例 / 法条库 / 心理疏导 / 新规速递 / **维权文书**
- **113 道题**（简答速查 43 + 单选 30 + 多选 12 + 判断 12 + 案例应用 10 + 流程排序 6）
- **维权文书一键生成**：投诉信、证据清单、研判报告，可复制 / 下载 .txt / 打印另存为 PDF
- 每案都有「排查核实 + 共情/生硬」双分支，练证据意识与沟通温度

## 快速开始

**方式一：直接玩（推荐）**

下载 `index.html`，双击用浏览器打开即可。全部逻辑、数据、样式都在这一个文件里，**无需联网、无需构建、无任何外部依赖**。

**方式二：本地起个静态服务**

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 法律口径（重要）

判官判定依据统一采用**双路径**判定式：

> **噪声污染 =（超标 ∧ 干扰）∨（未依法防控 ∧ 干扰）**
> —— 《中华人民共和国生态环境法典》第547条

- 分贝达标**不等于**不扰民：未依法采取防控措施（如不装减振垫、不限时停机）同样可能构成
- 社会生活噪声经劝阻、调解、处理未能制止仍继续干扰的，依《治安管理处罚法》（2025 修订 · 2026-01-01 施行）第 88/89 条处理
- 举报热线统一为 **12345**（原 12369 多数地区已并入 12345，个别地区仍可直拨但常转同一工单，**不必重复投诉**）
- **分贝仪读数仅供参考，不能单独作为法定取证依据**；真正管用的是日志、录音、排查、证人、沟通留痕
